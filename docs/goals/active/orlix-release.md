# Orlix Release Goal

Complete the repository-native agentic release harness and use it to promote one exact Orlix build through:

```text
L0 source and policy
-> L1 unit, oracle, golden, and reducer
-> L2 component integration
-> L3 complete simulator product matrix
-> L4 identical approved-iPhone product matrix
-> L5 archive, TestFlight upload, and processing confirmation
```

Completion requires app-visible `ORLIX-USERLAND-TCTI-OK` from real Linux userspace on the simulator and approved iPhone, identical capability contracts on both destinations, all forbidden behavior false, clean crash evidence, and confirmed TestFlight processing for the same product identity.

The active execution plan is `docs/plans/active/orlix-agentic-release-harness/PLAN.md`. Progress and evidence belong in its `IMPLEMENT.md`.

## Current Milestone

Add structured reducer linkage and dynamic remediation selection, then wire the validated semantic frontier into the live selector.

## Invariants

- Follow the selected envelope and post-run classifier before acting.
- Do not edit product runtime code unless current structured evidence explicitly sets `runtime_patch_allowed=true`.
- Do not treat proof refresh, generated evidence, or SHA drift as product implementation work.
- Never edit generated upstream Linux, mlibc, Coreutils, package, rootfs, report, reducer, or build trees directly.
- Complete the simulator matrix before phone execution, and complete the identical phone matrix before release execution.
- Use external-SSD-backed Xcode and simulator storage through the configured wrappers.
- Preserve honest readiness truth until L0 through L5 are proven for one build.

## Autonomous Loop

Inspect the active plan and current envelope, execute one authorized frontier action, classify the result, update `IMPLEMENT.md`, run focused and harness validation, request skeptical review, commit and push a coherent checkpoint, then repeat. Stop for forbidden behavior, an unclassified failure, missing external authorization, or evidence that cannot identify the owning layer.
