# Orlix

Orlix compiles upstream Linux into `OrlixKernel.xcframework`, pairs it with OrlixMLibC, and delivers the curated operating system through OrlixOS. Linux userspace remains normal Linux userspace, and Apple-platform mechanics remain private host integration.
