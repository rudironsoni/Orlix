# Validate and publish an Orlix release

As a release operator, I want one product identity to advance through the defined proof ladder so the archived and uploaded application matches the runtime evidence used to authorize it.

Simulator validation is mandatory. Physical-device validation and upload require explicit operator authorization, and every promoted tier must preserve the same semantic product fingerprint.
