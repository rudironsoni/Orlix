# Validate an authorized mobile terminal device

Run the identical app-hosted terminal capability contract only after the simulator ladder passes and an operator explicitly authorizes physical-device work. When selected for a release candidate, the device proof must preserve the exact candidate fingerprint and becomes a promotion requirement recorded by the release harness.
